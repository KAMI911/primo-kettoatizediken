# Kettő a tizediken (1024) – Primo (A/B monochrome + C/Pro colour)

Z80 assembly, ~2 KB. Slide the tiles, merge equal ones, reach **1024** (play on up to 8192).
Keys: arrow keys or `W A S D` = move, `R` = new game, `H` = help, `Q` or `BRK` = quit to BASIC, `M` = sound on/off, `C` = switch colour/mono drawing (only offered when colour hardware is detected).

| file (`build/`, each as `.ptp` and `.wav`) | what |
|---|---|
| `kettoatizediken-hu` / `-hu-bw` | Hungarian (tape name `ketto10-hu...`) |
| `kettoatizediken-en` / `-en-bw` | English (tape name `ketto10-en...`) |

Without suffix = universal (detects the colour model at run time; on a mono Primo it draws mono and has no `C`), `-bw` = monochrome only (never uses colour).
Texts live in `src/text_hu.inc` / `src/text_en.inc`, generated by `tools/gen_text.py` (accented capitals are extra glyphs).

`make` builds, `make test` runs the unit tests (rules, RNG, number printing) on an emulated Z80, `make shots` renders
`build/shot_bw.png` / `build/shot_color.png` from emulated video RAM. The z88dk toolchain runs from a digest-pinned Docker image.

Not run on a real Primo or a Primo emulator: colour RAM layout/palette follow the working Raktáros code (see
`references/hardware.md`); the 8-line vertical offset between the colour ($E700) and mono ($E800) screens is untested.
